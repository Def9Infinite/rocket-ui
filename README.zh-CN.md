# ORBITAL — 火箭发射直播叠加层套件（用于 OBS）

[English](README.md) · **简体中文**

一套面向火箭发射直播的广播级叠加层套件。**视频画面由你自己**在 OBS 中采集；这些页面是**透明叠加层**，叠加合成在画面之上。一个**控制面板**统一驱动所有叠加层 —— 它们之间始终自动保持同步。

## 文件

叠加层以 **2×（超采样）**渲染，从而在直播中保持锐利清晰 —— 请将每个 OBS 浏览器源设为下表所示尺寸，然后在画布上**缩放到 50%**（在画布上的实际占位是各数值的一半）。可在 URL 中用 `?s=<n>` 单独覆盖某个源的缩放比例（`?s=1` = 不超采样）。

| 文件 | 作用 | OBS 浏览器源尺寸（@2×） |
|------|------|--------------------------|
| `index.html` | **控制面板**（操作员仪表盘）—— *请勿放到直播画面上* | 以窗口/停靠面板方式打开 |
| `titlebar.html` | 任务名称 · 运载器 · LIVE · 状态标签 | **3840 × 168** —— 顶部 · 通栏 |
| `countdown.html` | T 减 / T 加 倒计时钟，暂停横幅 | **1120 × 376** —— 顶部居中 |
| `weather.html` | 实时发射场气象 + GO/NO‑GO | **600 × 800** —— 左下 |
| `rocket.html` | 运载器 / 各级参数块 | **640 × 1344** —— 右侧 · 随内容（随分节增多而增高） |
| `timeline.html` | 带事件标记的移动飞行时间轴 | **3840 × 208** —— 底部 · 通栏 |
| `ticker.html` | 滚动关键信息条（时间轴的替代） | **3840 × 144** —— 底部 |
| `trajectory.html` | **上升飞行轨迹动画**（WebGL 高分辨率地球 + 轨道）—— 完整场景 | **1920 × 1080**（1×，不超采样） |

### 飞行轨迹动画（`trajectory.html`）
一个独立的全屏视图（从控制面板的 **🛰 飞行轨迹** 按钮打开，或作为独立的 1920×1080 OBS 浏览器源 / 场景）。它以一个无边框的灰色陆地/海洋**地球**为底——该地球由高分辨率（1:10m）海岸线以 WebGL 渲染，因而在任意缩放下都保持清晰。在此之上，它会：高亮显示发射场，沿**计算得出的上升地面航迹**飞行（发射方位角由发射场纬度 + 目标轨道倾角推导得出 —— 53° 近地轨道朝东北，范登堡太阳同步轨道则朝*南*），随着模拟的 **T+** 推进而逐渐拉远视野，将你的时间轴事件作为标注触发，并以**最终轨道的地球视图**收尾（一个位于目标高度的倾斜环 —— 到载荷分离时运载器已真正入轨）。**重要节点（★）直接标注在上升路径上**，带点 + 标签 + T+ 时刻（与时间轴一致），侧边列表仅显示重要节点。完全**本地化（EN / 中文）** —— 它跟随控制面板的语言切换。轨道读取自载荷的目标轨道字段；你也可以在其底栏中覆盖设置高度 / 轨道倾角。**回收**按钮可加入一子级的返回过程：选择**返场**（返回发射场着陆）或**海上回收**（沿飞行方位角在下游海面着陆），一子级便会分离，沿自己的虚线航迹下降，并在标注出的回收点着陆。控制项：播放/暂停、重播、拖动、倍速、回收，以及按 `C` 输出干净画面（隐藏 UI）。

## 快速开始

1. **运行同步服务器**（必需 —— 正是它把实时更新推送给 OBS）：
   ```bash
   cd "Stream UI"
   python3 server.py 4187
   ```
   然后打开 `http://localhost:4187/index.html` —— 那就是控制面板。

   > ⚠️ 请使用 **`server.py`**，不要用 `python3 -m http.server`，并通过 **URL 加载叠加层，而非“本地文件”。**
   > OBS 浏览器源是各自独立的浏览器进程，彼此不共享存储；服务器负责在它们之间中继状态。普通的 `http.server` / `file://` 也能把叠加层加载出来，但它们**不会更新。**

2. **在 OBS 中**，把你的**视频采集**（显示器/窗口/摄像头）添加为最底层。

3. 为每个叠加层添加 **来源 → + → 浏览器**，**粘贴控制面板中 *OBS 浏览器源* 下显示的 `http://localhost:4187/…` URL**（保持**不勾选“本地文件”**），并按上表设置**尺寸**。在画布上摆放各个源 —— 控制面板的**节目监视器**给出参考布局。

4. 让**控制面板**始终在自己的窗口/停靠面板中打开。你在其中所做的一切都会即时更新所有源。

## 控制面板能做什么

- **语言** —— 标题栏中的 **EN / 中文** 切换会本地化整个界面**以及每一个叠加层**（状态、倒计时、气象、运载器参数、滚动条，以及通用的飞行事件标签）。该选择会被保存并同步到所有源。
- **时序** —— `开始倒计时`、`暂停`/`恢复`、预设（10:00 / 02:00 / 00:10 / LIFTOFF），或输入任意 `mm:ss`。
- **任务状态** —— 标题栏上的彩色状态标签。保持 **自动** 即自动跟随倒计时（待命 → 倒计时 → 暂停 → 飞行中），或强制指定某个状态：**待命**、**暂停**、**重设 T0**、**推迟**、**飞行中**、**发射成功** 或 **飞行失利** —— 各状态按颜色区分（发射成功为绿色、推迟为橙色、飞行失利为红色并带闪烁圆点）。
- **起飞 · T‑0（UTC）** —— 将 T‑0 设为一个绝对的 **UTC 日期/时间**；倒计时会锁定到那一刻（面板会以 UTC 显示当前的 T‑0）。相对的 `mm:ss` 预设依然可用，并以其换算后的 UTC 时间显示。
- **发射窗口与暂停原因** —— 设置窗口的**开启 / 关闭**时刻（UTC），倒计时叠加层会显示 `窗口 18:30–20:05 UTC`，并在窗口即将关闭时转为红色。你填写的**暂停 / 中止原因**（例如 `UPPER-LEVEL WINDS`）会在倒计时暂停，或状态为 暂停 / 推迟 / 飞行失利 时显示在时钟下方。
- **品牌** —— 填入**任务徽章图片网址**即可替换标题栏内置徽章，并可选择**主题色**；整套叠加层（包括飞行轨迹视图）会即时换肤。
- **发射条件** —— 气象叠加层会按条目列出 **适宜 / 不适宜** 明细。地面风、云层/降水与温度取自实时气象；**高空风**与**雷电**由你手动设置（气象数据源中没有这两项）。
- **底栏** —— `时间轴` / `滚动条`，外加一个 **透明** 开关，使条带半透明（去掉深色衬底；文字保留阴影，以便在明亮的视频上仍清晰可读）。时间轴采用纤细的双轨设计（≤100 px）。
- **发射场与气象** —— 选择一个发射台；实时气象从 Open‑Meteo 拉取（离线时回退为模拟数据），并据此计算出发射的 GO/NO‑GO。
- **运载器参数** —— 火箭参数块的每个字段都可编辑（发动机、推力、工作时间等）。运载器一行显示火箭的**运力**，与实际货物相区分。**有效载荷**（名称 / 客户 / 类型 / 质量 / 目标轨道）、**助推器**、**三级**与**上面级**是可选分节 —— 按任务逐个启用；它们仅在启用时出现在叠加层中（卡片会随之增高以容纳）。
- **运载器预设** —— 用 `载入预设` 快速加载内置运载器参数（Falcon 9 Block 5、Long March 2F、Long March 5、Electron）。
- **配置（文件）** —— `⤓ 保存配置` 会把**火箭参数 + 飞行时间轴**一并下载为单个可移植的 `.json` 文件；`⤒ 载入配置` 则把它读回。便于跨机器重新载入、备份或分享。
- **飞行时间轴** —— 添加 / 编辑 / 重排事件。时间可输入 `T+02:35`、`-1:00` 或 `145`（秒）；★ 表示重要节点（MECO、级间分离、整流罩分离、着陆…）。

快捷键：`Space` = 暂停/恢复 · `T` = 时间轴/滚动条 · `Esc` = 关闭对话框。

## 同步如何工作

OBS 浏览器源是**各自独立的浏览器进程**，**不**共享 `localStorage`，因此控制面板通过**同步服务器**（`server.py`）中继状态：面板将状态 `POST` 到 `/state`，每个叠加层轮询 `GET /state`（~300 ms）并应用它。`localStorage` 仍用作同浏览器内的快速通路以及持久化。时钟以时间戳形式存储，每个叠加层每帧在本地计算 T，因此无论同步延迟如何，倒计时都保持流畅。心跳每隔几秒重新推送一次状态，因此重启的服务器或新添加的源都会自动跟上。

**如果叠加层没有更新：**几乎可以肯定你运行的是普通 `http.server`，或把叠加层作为**本地文件**加载了。请改用 `python3 server.py`，并对所有源使用 `http://localhost` 的 URL。
